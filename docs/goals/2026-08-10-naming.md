# Goal: one vocabulary for keylink's caller surfaces

## Intent

keylink's public names encode the wrong distinctions. `System` means *runtime*
everywhere else and here names a served id-to-actor map; `Mounted` names the state
its value is not in; nine doors encode three ideas; and keylink's own verbs steal
15 ordinary English words from the user's RPC namespace, so `rpc Close()`,
`rpc Stop()` and `rpc Watch()` do not compile. Ship one deliberate breaking
change that fixes all of it: rename what is wrong, fold the proposal-era free
functions into methods where the type boundary permits it, collapse the doors,
and move keylink's verbs onto traits so the user gets those words back.

## Context

Repository `/Users/pedrocunha/repos/keylink`, branch `main`. Pre-1.0, single
owner, **no backward-compatibility obligation** — change everywhere and delete
the old path. No aliases, no re-exports, no deprecation wrappers.

**The reviewed proposal is `docs/proposals/2026-08-10-naming.md`.** It was
written against `f0f7df6`; its evidence and rulings remain authoritative except
where this goal explicitly amends them for merged PR #47, `c5b9134` (*Complete
actor correctness and generated service surfaces*). This goal is the source of
truth when the two documents differ.

PR #47 changed the baseline in four load-bearing ways: generated
`KeyedClient::at` already replaced the remote free `at`; generated
`LocalRef<'_>` plus `at_local(&System, id)` now provide typed local keyed calls;
`System::ended(&id)` now observes a mounted actor's ending; and the macro now has
name-collision guards for both `LocalRef::id` and `ActorRef::id`. Preserve those
capabilities and their current error/lifecycle semantics.

Almost everything public is generated by `macro_rules!` in
`keylink/src/macros.rs`. The registry is `keylink/src/actor/registry.rs`; the
local actor loop is `keylink/src/turns.rs`; the root re-exports are
`keylink/src/lib.rs`. `keylink/src/console.rs` expands `service!` **inside
keylink** and re-exports a narrowed set at `keylink::inspect`, so every rename
must survive that self-expansion.

## Scope

**In scope** — every item in §5 of the proposal:

- §5.1 `System`→`Registry`, `SystemBuilder`→`RegistryBuilder`,
  `KeyedClient`→`RegistryClient`, `keyed_alpn`→`registry_alpn`,
  `System::shutdown(&id, budget)`→`Registry::stop(&id, budget)` (budget kept),
  and preserve PR #47's `Registry::ended(&id)` unchanged in meaning. First rename
  the private `struct Registry<M>` in `actor/registry.rs` to `Shared<M>` in its
  own prerequisite commit.
- §5.2 `Mounted`→`Mountable`, keeping the type-level `#[must_use]` and its reason.
- §5.3 preserve the already-shipped `client.at(id)` while renaming its receiver;
  `keyed_service`/`keyed_serve`→`registry.service(allow)`/`registry.serve(&node, allow)`.
- §5.4 nine doors → four: `actor`, `spawn` unchanged; `setup(state)` and
  `restarting(factory, limit)` builders terminating in `.actor()` or `.mountable()`.
- §5.5 re-audit the two sentences against PR #47; preserve its corrected
  per-surface diagnostics rather than restoring proposal-era wording.
- §5.6 `deliver_to_singleton`/`deliver_to_actor`→`deliver_unkeyed`/`deliver_keyed`,
  `serving_of_singleton`/`serving_of_actor`→`serving_unkeyed`/`serving_keyed`.
- §5.7 add the curated prelude and capability-preserving extension traits;
  **delete** `Handle::is_busy`, `Handle::buffered`, `LocalRef::id`, and
  `ActorRef::id` (all have zero current call sites). Retire `__status`,
  `__reserve`, `__try_reserve`, and `__reserve_owned`. Preserve the exact PR #47
  generated-surface matrix: no surface gains or loses `rpc`/`tell`/`send`/`recv`/
  `blob`, transport, blocking, idempotency, governance, or error semantics.

**Out of scope**

- Every rename §2 refuses: `Handle<A>`, `Client`, `IdempotentClient` keep their
  names. `ActorRef`→`RemoteActorRef` is **not** taken in this goal.
- The verb table §3.2 and §3.3 refute — no `system.actor(id)`, no
  `mount(id, state)`, no `status(id)`, and nothing named `mount`/`stop`/`abort`
  on any peer surface.
- Renaming or removing PR #47's `LocalRef<'_>`, changing its `LocalError`, or
  replacing `at_local(&registry, id)` with a method. The free function stays:
  returning a generated service-specific reference from root `Registry<M>` would
  require a new extension seam, not a rename. Only its zero-use public `id()`
  accessor is deleted so `rpc Id` compiles.
- Every §9 open question: naming the `Governed` axis, `connect` against `dial`,
  the `with_idempotency` asymmetry, `Handler` beside `Actor`.
- The §11.4 pre-existing debt: the four `Reentrant` copies, the
  `compose::Names`/`Subscribers` merge.
- CI. It is off by decision and stays off.

**Blast radius**

## Public interface

```rust
// crate root
pub mod prelude;                    // the six extension traits below, nothing else
pub struct Registry<M>;             // was System<M>
pub struct RegistryBuilder<M>;      // was SystemBuilder<M>
pub struct Mountable<M>;            // was Mounted<M>
impl<M> Registry<M> {
    pub async fn stop(&self, id: &ActorId, budget: Duration) -> Option<Ended>;  // was shutdown
    pub fn ended(&self, id: &ActorId) -> Option<impl Future<Output = Ended> + Send + 'static>;
}
pub fn deliver_unkeyed(..);  pub fn deliver_keyed(..);
pub fn serving_unkeyed(..);  pub fn serving_keyed(..);

pub trait Wire { /* async key_state, watch, close */ }
pub trait BlockingWire { /* synchronous key_state, close */ }
pub trait WithIdempotency { type Output; /* with_idempotency */ }
pub trait Status { /* async status for Client, IdempotentClient, ActorRef */ }
pub trait Own { /* Handle: stop, abort, ended, is_running, with_state, status, reserves */ }
pub trait Servable { /* Handle and Registry: service, serve */ }

// generated module `svc`
svc::Registry  svc::RegistryBuilder  svc::Mountable  svc::RegistryClient
svc::LocalRef<'_>  svc::ActorRef<'_> // neither has an inherent id()
svc::registry_alpn()
svc::at_local(&registry, id) -> LocalRef<'_>  // preserved from PR #47
svc::setup(state) -> Setup<A>        // .observe(..) .feeds(..) .backpressure(..)
svc::restarting(factory, limit) -> Setup<A>
// Setup terminals: .actor() -> Handle<A>   .mountable() -> Mountable
impl RegistryClient { pub fn at(&self, id: ActorId) -> ActorRef<'_>; }
// service/serve are Servable trait methods, not impossible inherent methods on an alias.
```

`Client::connect` stays **inherent** — 87 call sites, and a trait cannot carry it
without breaking `Client::connect(&node, addr)` at the call site.

Unchanged and deliberately so: `Handle<A>`, `Client`, `IdempotentClient`,
`LocalRef<'a>`, `ActorRef<'a>`, `Actor`, `Handler`, `Calls`, `ActorId`, `Node`,
`Request`, `Response`, `Mail`, `Feed`, `Feeds`, `Mailbox`, `Permit`,
`OwnedPermit`, `Actors`, `alpn`, `service`, `serve`, `at_local`,
`blocking::Client`, `blocking::IdempotentClient`.

## Invariants

### Universal

- **No legacy, no compatibility shims.** Pre-1.0, single owner. Delete the old
  path; no alias, no re-export, no deprecation wrapper.
- **Single source of truth.** Each moved capability has one implementation and one
  authoritative doc source. Do not duplicate forwarders or documentation merely
  to span generated surfaces.
- **Fail loudly.** No silent fallback, no best-effort path, no swallowed error.
- **Fix at the root.** `superpowers:systematic-debugging`, never a workaround.
- **`#[must_use]` survives the move.** All nine doors carry it today with
  individual reason strings. `setup` and `restarting` need it, and every
  `Setup<A>` method returning `Self` needs it. `return_self_not_must_use` is
  `pedantic` and this workspace enables only `clippy::all`, so **nothing will
  remind anyone**.
- **No `unwrap`/`expect` outside a test module**, enforced by the workspace lints.
- **Review gates are evidence, not ceremony.** Prime/RLM review subagents use
  `openai-codex/gpt-5.6-luna` at max reasoning; never fable.

### Context-dependent, decided here

- **Preserve the PR #47 surface matrix exactly.** Use `Wire` for the three async
  client families' common `key_state`/`watch`/`close`, `BlockingWire` for the two
  blocking clients' synchronous `key_state`/`close`, `WithIdempotency` only where
  that method exists, `Status` for the async singleton clients and `ActorRef`,
  `Own` for `Handle`, and `Servable` for `Handle`/`Registry`. Associated outputs
  may preserve the current two `with_idempotency` return shapes. Do not add a
  method to a surface just to make a trait fit; do not box futures.
- **PR #47 capabilities survive the rename.** `LocalRef`/`at_local` and
  `Registry::ended` keep their behavior and targeted regression coverage.
  `LocalRef::id` and `ActorRef::id` are deleted; callers already supplied the id,
  and neither accessor has a current call site.
- **ALPN movement costs nothing before a stable release.** Do not price, group,
  schedule, or report a contract-hash move. The two literal pin tests remain
  ignored; property tests remain enabled.
- **Name-checking tests are deleted, not replaced.** A `compile_fail` whose claim
  is "this name is absent" passes for the wrong reason after a rename. Delete
  them and **do not add more**. `trybuild` is explicitly **not** adopted.
- **The private `Shared<M>` rename is a separate first commit.** The public
  `Registry` cannot take the name while the private type holds it.
- **Break records live in two places and either can rot alone** — the record
  prose and the `replay-anchors` row. An anchor quotes a source literal, and
  `cargo fmt` owns the line breaks it quotes, so re-count **after** every edit,
  including after `fmt`.
- **`keylink::inspect` must survive.** `console.rs` expands `service!` inside
  keylink and `lib.rs:294-312` re-exports a narrowed, partly `#[doc(hidden)]`
  set. Every new name that generated rustdoc cross-references must join that
  list or `mise run docs` goes red.
- **String literals name types no compiler reads.** Re-find the
  `#[diagnostic::on_unimplemented]` notes, generated-service prose, and the
  `rpc WhyEnded` docs against current `main`; update every renamed literal in the
  same commit rather than trusting proposal-era line numbers.
- **Testing:** the existing suite is the harness. Add tests only for the new
  behaviour — the eight-reserved-word `service!` block, and the builders'
  terminals. No mocks; keylink's tests drive real actors and real connections.

## Process

Work in an isolated worktree created with worktrunk — `wt switch -c <branch>`,
never raw `git worktree`, because `wt` runs the project's hooks. Atomic commits,
one logical change each, pushed as they land.

**A plan is required.** Run `superpowers:writing-plans` against this goal first
and save it under `docs/plans/`. The eight items have ordering constraints — the
`Shared<M>` prerequisite, and `anchors` re-registration after every literal move —
so the plan must sequence them, not just list them.

Flow: **Explore → Plan → one adversarial plan gate → Execute → one mandatory
merge gate → apply findings → PR to `main`.** Do not create an open-ended review
loop. Re-review only a Critical or structural fix, and target that fix plus its
blast radius.

- Plan and merge gates use independent `openai-codex/gpt-5.6-luna` subagents at
  max reasoning with `brooks-review` plus `superpowers:requesting-code-review`;
  add `brooks-audit` to the trait/interface review.
- Fixes are applied through `superpowers:receiving-code-review`. The reviewer
  never fixes its own findings. Fix every finding that brings real value,
  including Minor findings; report all counts.
- Run the invariant-compliance check in parallel with the merge gate. Grade the
  PR diff against every invariant and print a per-invariant verdict. An
  unevidenced invariant is failed. Re-open only for a Critical/structural miss.

**Gate discipline, from `AGENTS.md`.** Never kill a running gate — twelve runs in
one session were killed and each threw away every minute it had spent. Never
`--no-verify` except the two reasons `CONTRIBUTING.md` lists. Capture gate output
to a file with `tee` and read it there; never pipe a gated command through
`tail`, and never read `$?` after a pipe.
